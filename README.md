## 📌 Executive Overview
During Q2, HimShakti conducted a comprehensive supply chain and bio-waste processing audit across regional processing centers. Using Python, SQL, and Looker Studio, this business intelligence project identified an aggregate operational financial leakage of **17,203,520 INR**, with **Herbal Extract processing** accounting for **56.4% of total monetary losses**.

This repository contains the complete end-to-end analytics pipeline, exploratory notebooks, SQL scripts, AI prompting audit logs, executive data decks, and final Capstone report.

---

## 🛠️ Key Technical Stack & Methods
- **Data Processing & Analytics:** Python (`pandas`, `numpy`), Jupyter Notebooks, SQL queries
- **Business Intelligence & Dashboards:** Looker Studio interactive yield tracking
- **AI & Workflow Optimization:** Structured Prompt Engineering for KPI extraction, SOP generation, and risk modeling
- **Operations & Strategy:** Standard Operating Procedures (SOPs), Unit Economics, Root-Cause Analysis

---

## 📊 Key Business Findings
1. **Total Q2 Financial Leakage:** ₹17,203,520 across regional processing nodes.
2. **Primary Loss Driver:** Herbal Extract lines (₹9,702,785 / 56.4% loss share) due to shop-floor extraction inefficiencies at Center-A.
3. **Secondary Loss Streams:** Ginger (23.1% loss share) and Turmeric (20.5% loss share).
4. **Core Operational Fix:** Daily zero-point scale calibration SOPs, automated Looker Studio threshold alerts (>15% waste), and upcycled bio-waste monetization.
